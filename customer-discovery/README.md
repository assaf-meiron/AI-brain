# Customer Discovery — ראיונות גילוי (FollowIT)

תיקייה זו מרכזת תיעוד של ראיונות גילוי (discovery) שבוצעו מול משתמשים בשטח,
במטרה להבין כיצד נעשה שימוש במערכת **FollowIT** ביום‑יום, מהם הכאבים המרכזיים,
וכיצד נראית האינטגרציה הרצויה מול **SEARIAL** ו‑**GoFix**.

> הראיונות הוזנו מתוך סיכומים מצולמים. **פרטים מזהים (שמות אנשים, יחידות, שמות כלים
> ומזהים ספציפיים) הושחרו במקור** ומסומנים כאן כ‑`[מושחר]`.

## תמות חוצות‑ראיונות (Cross-cutting themes)

- **אקסל מקביל למערכת** — כמעט כל מרואיין מנהל טבלת אקסל משלו במקביל ל‑FollowIT
  (לתזמון, לסימון ביצוע, לתצוגה נוחה). סימן לפער ב‑UX/אמון בנתוני המערכת.
- **קשר ל‑SEARIAL וניהול פגי תוקף** — חזר בכל הראיונות: צורך במקור נתונים אחד מרוכז,
  ובידיעת תוקף פריט כדי לדעת אם הוא תקין.
- **דו"ח מנהלים כמרכז הכובד** — דרגים ניהוליים עוסקים בעיקר בדו"ח המנהלים; צורך חוזר
  ב**ייצוא לאקסל** לפי הסינון ובהפצת סיכומים.
- **גאנט / ציר זמן לטיפולים** — בקשה חוזרת לראות מתי מתקרבים טיפולים גדולים.
- **סינון** — מרכז עבודה, סטטוס (תקין/לא תקין), כלי, תדירות, דרג צוות; כולל צורך לסנן
  לפי שדות **חסרים** (טיפולים ללא מחלקה / ללא קבוצת מתכנן).

## מתודולוגיה

- מקור: סיכומי ראיונות מצולמים (4 תמונות; ראיון 3 מורכב משתי תמונות).
- שפה: הראיונות בוצעו בעברית; התיעוד נשמר בעברית בנאמנות למקור.
- מגבלה: חלקי טקסט הושחרו במקור ולא ניתנים לשחזור (`[מושחר]`).
